**Multi-ledger conflict resolution — this is the key insight:**

The marker itself IS the source of truth, not the ledger. Here's why a racing liar can't win:

1. Every marker is **Ed25519 signed by the subject's private key**. A liar can't forge a valid marker — they'd need the agent's private key.

2. The ledger only proves **when** something was posted, not **what's true**. So even if someone posts a fake marker to Ledger B right after we post the real one to Ledger A, the fake fails signature verification instantly.

3. The real attack surface is **timestamp manipulation** — "I departed at 3pm" vs the real 5pm. RFC 3161 timestamps from a trusted TSA defeat this because the TSA independently signs the time it received the hash. Multiple TSAs = multiple independent witnesses.

4. For ordering conflicts (two *valid* markers claiming different departure times), the resolution is: **earliest RFC 3161 receipt wins**, and multi-ledger posting is *redundancy not conflict* — same marker, same hash, posted to multiple places simultaneously. If the hashes match across ledgers, they're the same event. If they don't match, one is forged and fails signature verification.

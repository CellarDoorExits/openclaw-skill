> **Research date:** 2026-02-23
> **Deadline:** March 9, 2026 at 11:59 PM Eastern Time
> **Docket:** NIST-2025-0035
> **FR Doc:** 2026-00206 (published January 8, 2026)

## Important Clarification

The user's request referenced an RFI from NIST's "AI Agent Standards Initiative" announced Feb 17, 2026. The actual RFI with the March 9 deadline is **"Request for Information Regarding Security Considerations for Artificial Intelligence Agents"**, issued by CAISI in January 2026. The Feb 17 announcement launched the broader "AI Agent Standards Initiative" umbrella but pointed to this existing RFI as the current submission opportunity. There is no separate Feb 17 RFI.

## 1. Submission Portal

**URL:** <https://www.regulations.gov>
- Search for docket **NIST-2025-0035**
- Click "Comment Now!" button
- Direct docket link: <https://www.regulations.gov/docket/NIST-2025-0035>

**No other submission method accepted.** NIST explicitly states: *"NIST will not accept comments for this notice by postal mail, fax, or email."*

For accommodations, contact: **Peter Cihon**, Senior Advisor, CAISI — (202) 695-5661; `ai-agent-security@nist.gov`

## 2. Required Format

The regulations.gov portal allows you to either:
- **Type comments directly** into the web form, OR
- **Attach files** (upload)

The RFI does not specify a required file format (PDF, Word, etc.). Regulations.gov generally accepts PDF, Word (.docx), plain text, and other common formats. **PDF is the safest choice** for preserving formatting.

## 3. Page Limits & Formatting Requirements

**No page limit specified.** The RFI contains no explicit page or word limits.

**Formatting guidance:**
- Include "the relevant document number and title in the subject field" (i.e., reference 2026-00206 / NIST-2025-0035)
- Submit only once (no duplicates)

## 4. Numbered Questions — Yes

The RFI contains **5 topic areas with detailed numbered/lettered sub-questions**. Respondents are told:

> *"All responses should specify which questions are being answered."*

> *"Respondents need not address all questions in this RFI."*

**Priority questions** (explicitly flagged for respondents with limited bandwidth):
- 1(a), 1(d), 2(a), 2(e), 3(a), 3(b), 4(a), 4(b), 4(d)

### Question Structure:

1. **Security Threats, Risks, and Vulnerabilities** (5 sub-questions: a–e)
   - Unique threats to AI agents vs traditional software
   - Variation by capability, deployment, hosting, use case
   - Barriers to adoption from security risks
   - Evolution over time / future trajectory
   - Multi-agent system specific threats

2. **Security Practices for AI Agent Systems** (5 sub-questions: a–e, with sub-sub items)
   - Technical controls (model-level, system-level, human oversight)
   - Variation by context
   - Future evolution of controls
   - Patching/updating lifecycle
   - Existing cybersecurity frameworks' relevance

3. **Assessing Security** (4 sub-questions: a–d, with sub-sub items)
   - Methods during development
   - Assessment of particular systems
   - Documentation from upstream developers (open vs closed source)
   - User-facing documentation

4. **Deployment Environment Controls** (5 sub-questions: a–e, with sub-sub items)
   - Constraining agent access/environment
   - Modifying environments, undo/rollback
   - Managing counterparty interactions (humans, web services, IoT, other agents)
   - Monitoring methods
   - Open internet deployment tracking

5. **Additional Considerations** (5 sub-questions: a–e)
   - Tools for rapid adoption of security practices
   - Government collaboration priorities
   - Research directions
   - International approaches
   - Cross-disciplinary insights

## 6. Supplementary Materials / Linking Policy

The RFI states:

> *"Comments containing references, studies, research, and other empirical data that are not widely published should include copies of the referenced materials."*

**Interpretation:** You can reference external URLs (GitHub, npm, websites), but if the material isn't widely published/available, you should **attach copies** rather than just linking. For an open-source project on GitHub/npm, linking should be fine since it's publicly accessible, but attaching key documentation as supplementary files is safer.

## 7. Public Disclosure Warning

> *"All relevant comments received by the deadline will be posted at regulations.gov under docket number NIST-2025-0035 without change or redaction."*

**Do not include** personal or confidential business information you don't want public.
